# Basal Ganglia Explorer

[Open the interactive explorer](https://owen-ferguson.github.io/Basal_Ganglia_Explorer/)

This tool shows how dopamine affects activity in a simplified basal ganglia circuit. Move the slider to change the amount of dopamine input from the substantia nigra pars compacta (SNc) and see how activity changes across brain regions in the direct and indirect pathways.

I built this while writing my PhD thesis on Parkinson’s disease. I couldn’t map out all the changes on paper, so I made an interactive version that let me follow both pathways as I adjusted dopamine input.
